Cumulative review

Re-reading feels like learning but mostly builds fluency, the illusion of mastery. Retrieving from memory, cold, with topics shuffled, is what builds storage strength.

How to use this

This set spans all eleven teaching lessons, weighted toward the newer material (the ORM, serializers, generic views, auth), and it is shuffled every run.1 Interleaving the whole course is harder than drilling one lesson, and that difficulty is what makes it stick. Most questions pit the right answer against a near-miss. Answer from memory first, then hit Shuffle & retry and run it again days later.

Go deeper. Missed the same lesson twice? Flag it; it is worth re-explaining a different way. Clearing this cold means you can trace a request from URL to response, through the verb dispatch, serializer, queryset, and the auth gate, and say what each layer is for.
