Interleaved review

Re-reading the lessons builds fluency, the feeling of knowing. Retrieving each answer cold, with all nine lessons shuffled together, builds storage strength: the version that survives an interview, where there is nothing to look at and no time to reconstruct.

How to use this

Questions are drawn from all nine lessons and shuffled every run, by design. Interleaving beats reviewing one lesson at a time, and the extra difficulty is the reason it works.1 Most questions pit the right answer against a near-miss, the version that sounds right and is subtly wrong, because the near-miss is what a nervous candidate says. Answer out loud from memory before reading the feedback. Then hit Shuffle and retry, and run it again in a few days.

Go deeper. Missed the same lesson twice? Say which one and it is worth re-explaining a different way. The harder test is the whiteboard sheet: redraw the reference architecture from a blank page and say the justification for each box out loud.
