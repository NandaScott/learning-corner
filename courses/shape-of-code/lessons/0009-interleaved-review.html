Interleaved review

Re-reading the lessons builds fluency, the feeling of knowing. Retrieving each judgment cold, with all eight shuffled together, builds storage strength: the reflex that fires in a design discussion, where there is no time to look anything up.

How to use this

Questions are drawn from all eight lessons and shuffled every run, by design. Interleaving the principles, rather than reviewing one lesson at a time, is harder, and that difficulty is what makes them stick.1 Most questions pit the right answer against a near-miss, the version that sounds right and is subtly wrong, because near-misses are what actually get proposed in design conversations. Answer from memory before reading the feedback. Then hit Shuffle & retry, and run it again in a few days. The spacing is the second half of durable memory.

Go deeper. Missed the same lesson twice? Say which one. It is worth re-explaining a different way, or drilling that one distinction on its own. The real test is not this quiz: it is the next non-trivial ticket, where the design note gets written before the code and the last question either has an answer or does not.
