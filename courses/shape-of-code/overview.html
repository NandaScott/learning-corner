The Shape of Code

Conceptual correctness: whether the code's structure makes the domain's rules hard to break, rather than whether it produces the right output today. Eight lessons on the judgment that happens before the first line of code, the vocabulary for arguing it with other engineers, and the ten-minute written note that puts both in front of the keyboard. Eight lessons, an interleaved quiz, a glossary, and a printable template.
