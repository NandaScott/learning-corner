Interleaved review

Re-reading the lessons builds fluency, the feeling of knowing. Retrieving each answer cold, with all nine lessons shuffled together, builds storage strength: the version that is still there in a design review, when a config has to be judged on the spot.

How to use this

Questions are drawn from all nine lessons and shuffled every run, by design. Interleaving beats reviewing one lesson at a time, and the extra difficulty is the reason it works.1 Most questions set the right answer against a near-miss: the version that sounds right and is subtly wrong, such as treating a term like a hit on MaxDeliver, or expecting an advisory to be stored. Answer from memory before reading the feedback. Then press Shuffle and retry, and run it again in a few days.

Ask follow-up questions. Missed the same lesson twice? Say which one, and it can be explained a different way. The harder test is the cheat sheet with its tables covered: fill in the retention and give-up outcome matrix from a blank page.
